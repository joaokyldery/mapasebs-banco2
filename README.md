
# MapaSEBS — Banco de Dados II

Análise e Desenvolvimento de Sistemas.

## Acesso ao sistema (uso do professor)

Professor, para acessar o sistema e realizar testes de cadastro e exclusão de pontos de coleta, utilize as informações abaixo:
- Chave administrativa: novoponto

## Sobre o projeto

O MapaSEBS é uma aplicação web para cadastrar,
visualizar, editar e excluir pontos de coleta
de materiais recicláveis em um mapa interativo.

O sistema utilizará PostgreSQL com a extensão
PostGIS para armazenar dados espaciais.

## Tecnologias

- Node.js e Express
- PostgreSQL e PostGIS
- HTML, CSS e JavaScript
- Leaflet e OpenStreetMap
- Nominatim
